# 拾光 v2.0.0

个人日记 + 记账 Android 应用。本仓库只分发安装包，不含源码。

## 下载

到 [Releases](https://github.com/X-Natto/Gleamer/releases) 下载 `Shiguang-v2.0.0.apk`。

## 安装

1. 下载 APK 后传到手机
2. 点击安装，系统提示「未知来源」时允许本次安装
3. 覆盖升级不需要卸载旧版，数据保留
