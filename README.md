# 拾光

一个完全由 AI 写出来的日记 + 记账应用。

界面、交互、数据结构、安卓打包，都是我和 AI 一句一句聊出来、改出来的，没有套用现成的 App 模板。所以它长得不太像常见的记账软件，用起来更接近一本自己的本子。

## 它是做什么的

拾光把日记和记账放在同一个地方。白天随手记一笔花了多少，晚上补一段今天发生了什么，翻的时候是同一条时间线，不用在两个 App 之间来回切。

- **日记**：按天写，可以放照片、视频和语音，配心情和天气；日历和时间线两种翻法
- **记账**：日常收支、账户余额、分类统计和趋势图，支持多个账本
- **固定收支**：房租、会员费这类可以设成按天 / 周 / 月 / 年自动记，一笔大额也能摊到每天
- **计算器**：房贷一类可以算等额本息和等额本金的每期还款、总还款额；定投可以按每期投入和预期收益率，估到目标日期能攒下多少
- **离线可用**：内容只存在手机本地，没有账号，也不上传云端
- **隐私保护**：数字密码、九宫格、指纹都能用来解锁；导出的备份可以加密码
- **备份与恢复**：手动导出，也能按 1 天 / 3 天 / 7 天自动备份，换手机时导入就回来了

适合想安静记点东西、顺便记记账的人。不用注册，没有广告，数据始终在自己手里。

## 下载安装

到 [Releases](https://github.com/X-Natto/Gleamer/releases) 下载最新的 APK，传到手机上点击安装。

系统提示「未知来源」时允许这一次即可。覆盖升级不用卸载旧版，原来的日记和账目都会保留。

## 关于升级

从 v2.1.0 开始，应用里可以直接检查新版本：「菜单 → 版本更新 → 检查更新」。

也可以在「设置 → 版本更新」里打开自动检查，进入应用时会自己看一眼 GitHub 上有没有新版。发现新版本会先问你要不要下载，完全可以稍后再说，不影响继续用。
